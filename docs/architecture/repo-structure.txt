credit-credix/
=================
Root directory for the Credit Credix product — an AI credit-coaching
credix with persona "Rahul" for the Indian retail credit market.

Architecture in one line:
  LangGraph deterministic-routed multi-agent system, sitting over a
  Postgres + Redis + MongoDB + Snowflake data plane, exposed via FastAPI,
  driven by Grok at the LLM layer.

Build phases (enforced by which directories are real vs scaffold):

  PHASE 1   raw_data/                ← CURRENT FOCUS
            (bureau resolver, user data, user memory, precomputed,
             assembler — everything the agent reads from)

  PHASE 2   graph/  guardrails/  memory/  persona/  llm/  api/  workers/
            (Turn-1 nodes, specialist subgraphs, guardrail brackets,
             memory infra, persona synthesizer, FastAPI surface)

  PHASE 3   tools/                   ← TOOL CALL MODULE / CREDIT BRAIN, LAST
            (deterministic engine, policy & rules KB, decision trees,
             prediction models, product catalog, intent resolver)

────────────────────────────────────────────────────────────────────────
WHAT GOES WHERE (decision rules, so the boundary stays clean)
────────────────────────────────────────────────────────────────────────

raw_data/   = WHAT THE AGENT READS FROM
            Content layer. Owns: bureau resolution, declared user facts,
            memory content (prose, constraints, goals, transcripts),
            and precomputed derived values. Produces the single
            PII-stripped JSON payload the agent sees per turn.

memory/     = HOW THAT CONTENT IS STORED
            Infra layer. Postgres JSONB + Redis cache + Mongo audit +
            LangGraph checkpointer. raw_data/user_memory/ uses memory/
            as its persistence backend; memory/ knows nothing about
            credit semantics.

graph/      = ORCHESTRATION
            CredixState, deterministic router, Turn-1 nodes,
            specialist subgraphs. Reads from raw_data/, writes via
            memory_writeback (off hot path).

guardrails/ = BRACKETS
            Pre and post. Pre runs before any specialist; post runs
            before compose. Numeric traceability lives here.

persona/    = VOICE
            Applied ONLY at the synthesizer layer inside the single
            render node. Never in tool outputs, never in memory writes.

tools/      = CREDIT BRAIN
            Deterministic engines, policy KB, decision trees, prediction
            models, product catalog, intent resolver. Built LAST so the
            data and control planes are stable before the reasoning
            surface is wired in.
