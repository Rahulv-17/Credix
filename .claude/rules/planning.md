# Planning rules

- Any task with 3+ steps or touching more than one module requires a written plan in `tasks/todo.md` before the first edit.
- Enter plan mode (`/plan`) before architectural decisions. Iterate once. Then execute.
- Update phase status in `tasks/todo.md` in the same turn as the work — never let a phase stay `in_progress` across sessions without a handoff note.
- For research-heavy phases, update `tasks/findings.md` after every 2 view/search operations. Do not batch.
- If something goes sideways mid-task, stop and re-plan. Don't keep pushing.
- One phase per session if possible. Pick it at session start. Write it. Execute it. Close it.
